TRACKLINE 3.0

Drop-in update for the existing Trackline GitHub Pages app.

DATA SAFETY
- Trackline continues to use the same IndexedDB database name: runnerRPG.
- Uploading these app files to the SAME GitHub repository / SAME Pages URL is designed to retain existing data.
- Always download a JSON backup before updating.
- Do not clear browser/site storage while updating.

UPDATE YOUR CURRENT GITHUB REPOSITORY
1. Open Trackline > Settings > Download backup.
2. On GitHub, open the SAME trackline repository you already use.
3. Upload/replace index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png and .nojekyll with these files.
4. Commit to main.
5. Wait for GitHub Pages deployment.
6. Open your existing Trackline app/site.
7. Use the Update prompt when it appears, or close/reopen after deployment.

WHAT IS NEW
- Multiple sessions per day (AM/PM/etc.), including Bike and Elliptical.
- Phase-aware September-to-track-season guidance.
- Ordered daily workflow: morning, pre-run, warm-up, during, post-run, evening.
- Mobility and balance micro-dose.
- Cross-training double guidance that counts cross-training as real load.
- Smart trends: 7-day running, sRPE load, 28-day sleep/pain/cross-training, easy-run efficiency.
- Data flags for load jumps, low sleep, pain and dense hard-day clusters.
- Performance benchmark system and development dashboard.
- Reference library for pre-run, post-run, mobility, plant-forward fuelling and cross-training.

BACKUPS
Use Settings > Download backup at least weekly and keep the JSON file outside the device/browser when possible.
